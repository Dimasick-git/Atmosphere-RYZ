# thermosphère

## English (summary)

thermosphère is a work-in-progress hypervisor that aims to provide functionality at
EL2, which Horizon OS leaves unused.

## Русский (подробно)

thermosphère — реализация гипервизора (в разработке). Назначение — предоставить
функциональность на уровне EL2, не используемом Horizon OS.
